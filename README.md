# TempConvert: A Simple Temperature Conversion Tool

## Overview
TempConvert is a Python-based console application designed to perform temperature conversions between Celsius, Fahrenheit, and Kelvin.

The project focuses on logical problem-solving, user interaction, and mathematical conversion techniques.

## Features
- Celsius to Fahrenheit
- Fahrenheit to Celsius
- Celsius to Kelvin
- Kelvin to Celsius
- Console-based User Interface
- User-friendly Interaction

## Technologies Used
- Python
- Conditional Statements
- Functions
- User Input Handling

## Objective
To build a simple and interactive temperature conversion application while improving logical programming skills.

## Key Learning Outcomes
- Mathematical Logic
- Console Application Development
- User Input Handling
- Problem Solving
- Python Fundamentals
